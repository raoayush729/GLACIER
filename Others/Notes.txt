what is kurtosis?

Kurtosis is a statistical measure that tells us how much the data is concentrated in the tails — especially how likely we are to see extreme values/outliers compared with a normal distribution.
Think of a dataset as having:
Center → normal/typical values
Tails → unusually low and unusually high values


####  Kurtosis mainly helps us understand how heavy or light those tails are.  ###


Simple example
Imagine these two datasets:
Dataset A:
10  11  12  13  14  15  16
Dataset B:
10  11  12  13  14  15  100
Dataset B has an extreme value 100.
That extreme value contributes to heavy tails, so its kurtosis will be much higher.

Whats a p-value?

A p-value tells us how unusual our result is if H₀ (null hypothesis) is actually true.

"If H₀ were true, how likely is it that I would get a result this extreme?"

For example:

p-value = 0.20

means roughly:

If H₀ is true, results this extreme are not particularly unusual.

But:

p-value = 0.01

means:

If H₀ is true, getting a result this extreme would be quite unusual.



Z-SCORE
↓
Measures how far the result is from the hypothesized mean.

SIGNIFICANCE LEVEL
↓
Sets how strict we are when deciding whether that result is unusual enough.

P-VALUE
↓
Tells us how unusual the result actually is under H₀.

ANOVA -
its a statistical analysis or method used to compare the means of 2 or more group within each other 

Factors-  These are the major subject like medicines
levels-  these are the levels of major subject like 10mg, 15mg, 20mg 

Assumtions in Anova:-
1 normality of sample distribution mean - the distribution of sample mean is normally distributed 
2 absence of outlier - outliers needs to be removed from the dataset
3 homogenity of variance - each one of the population has same variance, population variacnce in different levels of each indepenedent are equal
4 samples are indepenedent and random 
These needs to be satisfied before doing an anova test 

Types of anova 
1 one way anova - one factor with atleast 2 levels (indepenedent)
eg - doctor wants to test a new medication to decrease headache
    they split the participants in 3 conditions[10mg,20mg,30mg]
    doctor asks the participant to rate the headache[1-10]

            medication = factor
            levels = [10mg,20mg,30mg]   

the mgs are indepenedent there value are not affected by any other levels

2 two way anova (repaeted measures anova) - one factor with atleast two levels (dependent)

                Running = factor

                  7         4         3

here in the running it is possible that runner's covering distance is less and less day by day like 7 - 4 - 3
so thers is some dependency because of day1 2 and 3

ANVOVA TESTS STEPS :


    # Step 1 → H0 and H1


    # Step 2 → N = total rows * total columns,
    #          n = total rows, 
    #          a = total column(levels), 
    #          α = significance level


    # Step 3 → degrees of freedom 
    #          df between = a-1
    #          df within = N-a


    # Step 4 → TOtal Degree of freedom = N - 1


    # Step 5 → F critical value  = F distribution table (df between(column), df within(row))


    # Step 6 → SS between = summation of all squared values in every column(levels) saparted by column(levels) / n - summation of all values in every column(levels) saparated by column(levels) / N 
    #          SS within  = summation of the whole sample values squared of all columns(levels) - summation of all squared values in every column(levels) saparted by column(levels) / n


    # Step 7 → MS between = ss between / df between 
    #          MS within = ss within / df within


    # Step 8 → F statistic = varance between sample / variance within sample = MS between / MS within


    # Step 9 → Decision  = if the F statistics is greater than critical value then we reject the null hypothesis otherwise fail to reject

if __name__ == "__main__":

It basically means:

"Only run the code below this line if this Python file is being run directly."

That's it.

Example

Suppose export_manager.py contains:

class ExportManager:
    ...
    

if __name__ == "__main__":
    print("Testing ExportManager")

If you run:

python export_manager.py

Python says:

I am running export_manager.py directly
        ↓
__name__ == "__main__"
        ↓
YES
        ↓
Run the testing code

So:

Testing ExportManager

gets printed.

But what if another file imports it?

For example:

from export_manager import ExportManager

Now export_manager.py is not being run directly.

It's being imported by another Python file.

Therefore:

if __name__ == "__main__":

is false.

The testing code underneath it doesn't execute.

But the class still gets imported.

1. QApplication — Runs the GUI application
It sets up the application and manages GUI events, such as clicks, scrolling, and window interactions. 
It does not create the window's contents.
app = QApplication(sys.argv)


2. QWidget — Creates the main window
This is the container where we place the dataset information and table.
window = QWidget()
window.setWindowTitle("Glacier")
window.resize(1200, 750)
By itself, the window is empty.


3. QVBoxLayout — Arranges the contents
Places the information label above the data table.
layout = QVBoxLayout(window)
layout.addWidget(info)
layout.addWidget(table)


4. QLabel — Displays dataset information
Shows the file name, path, type, shape, and last operation at the top.
info = QLabel("Dataset information")


5. QTableView — Displays the spreadsheet-like table
Provides the visible rows, columns, scrolling, and table area. It needs a model to supply the actual cell data.
table = QTableView()
table.setModel(model)


6. QHeaderView — Controls the table headers
Lets us configure how column headers behave, including manually resizing columns.
table.horizontalHeader().setSectionResizeMode(QHeaderView.ResizeMode.Interactive)


7. QAbstractTableModel — Connects our data to the table
We inherit from this class to build our own TableModel, which tells the table how many rows and columns exist and what value belongs in each cell.
class TableModel(QAbstractTableModel):
    ...
This is the base class; it isn't the visible table.


8. Qt — Provides ready-made GUI settings
Used to specify things like what data to display and whether label text can be selected with the mouse.
Qt.ItemDataRole.DisplayRole





---------------------------------------------How all these pieces work together

QApplication

Manages the application

QWidget — Main window
QVBoxLayout — Arranges everything
QLabel

Dataset details

QTableView

Visible table


QHeaderView controls the headers


The table gets its data from our TableModel, built using QAbstractTableModel.



Important: 
QTableView displays the table, but the TableModel tells it what data to display. 
QApplication manages the overall GUI, while QWidget provides the window itself.
